## 1. 완료된 것

- **Baseline 확정**: G50_F0 (Ge 50%, FR 0) — Strain_Impact=1/0 비교로 응력→전기 결합이 실제로 작동함을 확인(IdSat_norm +227% 등, 방향성이 eSiGe pMOS 문헌과 일치)
- **실제 Sentaurus 스크립트 4개 확보·검토** — 단, Synopsys 라이선스 예제 기반 코드라 재배포 조항 미확인 상태라 `Share` 저장소(public)에는 올리지 않기로 함. 로컬 보관 + 팀이 무엇을 바꿨는지는 문서로만 서술(코드 원문은 비공개)
- **Ge%/FR 스윕 값 확정**: Ge% `[30, 40, 50, 60, 70]`(50% 중심), FR `[0, 10, 20, 30, 35]`(35nm = fin 전체 높이와 정확히 일치) — `values_confirmed: true`, 25격자점 본 스윕 착수 가능
- **STE 정규화 방법 파악** — 실제 구현은 채널 fin 영역 전체의 체적평균 방식. 게이트 계면 근처 단일점 근사값과 실측 비교한 결과 **53.9% 차이 + 한 성분은 부호까지 반전** — 무시할 수 없는 차이라 지금 하나로 확정하지 않고, 25격자점 스윕에서 두 값을 모두 수집한 뒤 최종 결정하기로 함(provisional). 단일점 근사값 자체는 창 크기를 줄여도 값이 안정적(0.8% 차이)이라 메쉬 문제로 인한 노이즈는 아님을 확인
- **대시보드 파이프라인 버그 수정** — 스윕 CSV가 없어도 첨부물(사진/메모)만으로 상태가 표시되도록 개선
- **대시보드 데이터 정합성 버그 수정** — 체크박스 담당자 키가 실제 과제 담당자와 어긋나 있던 문제(예: 담당이 다른 사람인데 엉뚱한 이름 키로 저장되던 것) 바로잡음
- **문서 전반 동기화** — 루트 README·baseline README·과제 정의 파일의 스크립트 관련 서술을 실제 상태로 갱신
