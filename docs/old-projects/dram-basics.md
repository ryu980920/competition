> 개정: 2026-08-02 (Rfillet → DBCAT). 경위는 [devlog.md](../devlog.md) 참고.

이 문서는 **DRAM에 대해 아무것도 모른다는 전제**로 쓰였습니다. 반도체 소자 수업에서 MOSFET을 한 번쯤 들어봤다면 충분하고, 그것도 헷갈리면 2장에서 필요한 만큼만 짚고 갑니다. 순서대로 읽으면 마지막에는 우리 프로젝트의 주제 문장이 왜 그렇게 쓰였는지 이해할 수 있습니다.

> **"BCAT는 게이트를 리세스 안에 묻으면서 표면 근처에 게이트-드레인 겹침이 남고, 그 겹침부에 전계가 집중돼 GIDL이 생겨 DRAM 리텐션을 떨어뜨린다. 우리는 그 겹침을 질화막으로 줄이는 것(DBCAT)과 접합 도핑을 낮추는 것, 이 두 방법이 서로 어떻게 상호작용하는지를 본다."**

## 1장. DRAM이란 무엇인가

### 1-1. 컴퓨터 안에서 DRAM의 자리

컴퓨터에는 데이터를 저장하는 장치가 여러 층으로 있습니다. 위로 갈수록 빠르지만 비싸고 작으며, 아래로 갈수록 느리지만 싸고 큽니다.

| 계층 | 예시 | 속도 | 특징 |
|---|---|---|---|
| 레지스터 / 캐시 | CPU 내부 SRAM | 가장 빠름 | 트랜지스터 6개로 1비트. 빠르지만 면적을 많이 차지해 용량이 작음 |
| **주기억장치** | **DRAM (우리가 다룰 것)** | 빠름 | 트랜지스터 1개 + 커패시터 1개로 1비트. 싸고 집적도가 높지만 전원이 꺼지면 사라지고, 켜져 있어도 주기적으로 되살려야 함 |
| 보조기억장치 | NAND 플래시 (SSD) | 느림 | 전원이 꺼져도 유지됨(비휘발성) |

여러분이 "메모리 16GB"라고 말할 때의 그 메모리가 DRAM입니다. 삼성전자와 SK하이닉스가 세계 시장을 주도하는 분야이기도 합니다.

### 1-2. DRAM의 D는 왜 Dynamic인가

DRAM은 Dynamic Random Access Memory의 약자입니다. 여기서 **Dynamic(동적)**이라는 말이 이 소자의 모든 특성을 결정합니다.

> **DRAM은 데이터를 커패시터(축전기)에 전하로 저장합니다. 그런데 전하는 시간이 지나면 반드시 새어나갑니다. 그래서 데이터가 사라지기 전에 주기적으로 다시 채워 넣어야 합니다. 이 "가만히 두면 사라진다"는 성질 때문에 Dynamic이라 부릅니다.**

이 문서 전체가, 그리고 우리 프로젝트 전체가 결국 이 한 문장에서 파생됩니다. **전하가 새는 것 = 누설전류(leakage current)**이고, 이걸 얼마나 잘 막느냐가 DRAM 설계의 핵심 싸움입니다.

> 💡 **비유**: 물이 조금씩 새는 양동이에 물을 담아두고 "물이 있음 = 1, 없음 = 0"으로 정보를 기록한다고 생각해보세요. 물이 다 새기 전에 주기적으로 다시 채워야 정보가 유지됩니다. 그 "다시 채우는 행위"가 **리프레시(refresh)**이고, "얼마나 오래 버티는가"가 **리텐션 타임(retention time)**입니다.

## 2장. MOSFET 최소 복습

DRAM 셀에 들어가는 트랜지스터는 MOSFET입니다. 이미 익숙하면 2-3절만 보고 넘어가도 됩니다.

### 2-1. MOSFET은 결국 스위치다

MOSFET에는 4개의 주요 부위가 있습니다.

- **소스(Source)**: 전하 운반자(전자)가 출발하는 곳
- **드레인(Drain)**: 전하 운반자가 도착하는 곳
- **게이트(Gate)**: 스위치의 손잡이. 여기에 전압을 걸면 소스-드레인 사이에 전류가 흐를 길(채널)이 열림
- **바디/기판(Body/Substrate)**: 소자가 놓인 바탕. 보통 접지되거나 음전압이 걸림

게이트와 채널 사이에는 아주 얇은 절연막(**게이트 산화막**, gate oxide)이 있습니다. 게이트는 채널에 직접 닿지 않고, 전기장으로 원격 조종하는 셈입니다. 이 산화막 두께가 우리 baseline에서는 **5nm**입니다.

### 2-2. 문턱전압(Vth)

> **문턱전압(Threshold Voltage, Vth) = 트랜지스터가 켜지기 시작하는 게이트 전압**

게이트 전압을 0부터 천천히 올리면, 어느 지점부터 갑자기 전류가 확 늘어납니다. 그 지점이 Vth입니다. Vth가 너무 낮으면 꺼야 할 때 제대로 안 꺼지고(누설 증가), 너무 높으면 켜기 위해 큰 전압이 필요해집니다(전력 소모·속도 저하). 적절한 값으로 맞추는 것이 소자 설계의 기본 과제입니다.

### 2-3. 이 프로젝트에서 특히 중요한 개념: 접합(Junction)

소스/드레인은 기판과 반대 극성으로 도핑되어 있습니다. 예를 들어 기판이 p형이면 소스/드레인은 n형입니다. 이 둘이 만나는 경계면을 **pn 접합(junction)**이라고 합니다.

접합에는 자연스럽게 전기장이 생깁니다. 그리고 여기에 외부 전압이 걸리면 전기장이 더 세집니다. 전기장이 아주 세지면 원래는 못 지나갈 전자가 억지로 넘어가는 현상이 생기는데, 이게 나중에 다룰 **GIDL**의 원인입니다.

> **기억할 것**: 접합 부위의 도핑 농도가 높을수록 → 그 부위 전기장이 세짐 → 누설이 커짐. 그래서 **접합 도핑을 낮추면 누설이 줄어듭니다.** (이것이 우리 프로젝트의 두 번째 변수입니다)

## 3장. DRAM 셀의 구조와 동작 (1T1C)

### 3-1. 1T1C — 트랜지스터 1개 + 커패시터 1개

DRAM의 1비트짜리 저장 단위(셀)는 놀랍도록 단순합니다.

> **1T1C = 1 Transistor + 1 Capacitor.** 커패시터가 데이터(전하)를 저장하고, 트랜지스터는 그 커패시터로 가는 문을 여닫는 스위치 역할을 합니다.

이 트랜지스터를 **접근 트랜지스터(access transistor)** 또는 **셀 트랜지스터(cell transistor)**라고 부릅니다. **우리 프로젝트가 다루는 BCAT가 바로 이것입니다.**

### 3-2. 배선 이름 익히기

| 이름 | 연결 위치 | 역할 |
|---|---|---|
| **워드라인 (Word Line, WL)** | 접근 트랜지스터의 게이트 | "이 행을 열어라" — 스위치를 켜는 선 |
| **비트라인 (Bit Line, BL)** | 접근 트랜지스터의 드레인(또는 소스) | 데이터가 실제로 오가는 통로 |
| **스토리지 노드 (Storage Node)** | 트랜지스터 반대쪽 + 커패시터 | 전하가 저장되는 지점 |

DRAM은 이 셀들이 가로세로 격자로 수십억 개 배열된 구조입니다. 특정 셀에 접근하려면 그 셀이 속한 워드라인(행)을 켜고, 해당 비트라인(열)에서 읽으면 됩니다.

### 3-3. 쓰기(Write) 동작

1. 워드라인에 전압을 걸어 접근 트랜지스터를 켠다 (문을 연다)
2. 비트라인에 쓰고 싶은 값에 해당하는 전압을 건다 (1이면 높은 전압, 0이면 낮은 전압)
3. 전하가 비트라인에서 커패시터로 흘러들어가 저장된다
4. 워드라인 전압을 내려 트랜지스터를 끈다 (문을 닫는다). 전하가 커패시터 안에 갇힌다

### 3-4. 읽기(Read) 동작 — 그리고 파괴적 읽기

읽기는 조금 까다롭습니다. 커패시터에 저장된 전하량이 워낙 작아서, 단순히 "전압을 재는" 방식으로는 읽을 수 없기 때문입니다.

1. 비트라인을 미리 중간 전압(보통 VDD/2)으로 충전해둔다. 이것을 **프리차지(precharge)**라고 한다
2. 워드라인을 켜서 커패시터와 비트라인을 연결한다
3. 커패시터에 전하가 있었으면 비트라인 전압이 아주 살짝 올라가고, 없었으면 아주 살짝 내려간다. **이 변화는 수십 mV 수준으로 매우 작다**
4. **센스앰프(sense amplifier)**가 이 미세한 차이를 증폭해 0인지 1인지 판별한다
5. 문제: 이 과정에서 커패시터의 전하가 비트라인으로 나눠져 원래 저장값이 망가진다. 이를 **파괴적 읽기(destructive read)**라고 한다
6. 그래서 읽은 직후, 판별한 값을 곧바로 셀에 다시 써넣는다. 이를 **리스토어(restore)** 또는 라이트백(write-back)이라고 한다

> 💡 여기서 등장한 "수십 mV의 미세한 차이"가 중요합니다. 이 차이를 **ΔV**라고 부르는데, 만약 전하가 새서 저장량이 줄어들면 ΔV도 작아지고, 결국 센스앰프가 0인지 1인지 구분하지 못하게 됩니다. 즉 **누설 → ΔV 감소 → 판독 실패 → 데이터 손실**이라는 사슬이 만들어집니다.

## 4장. 리프레시와 리텐션

### 4-1. 리텐션 타임이란

> **리텐션 타임(Retention Time) = 셀에 데이터를 쓴 뒤, 전하가 새어나가 판독 불가능해지기까지 버티는 시간**

일반적인 DRAM 규격에서는 셀이 최소 **64ms(밀리초)** 정도는 버텨야 한다고 요구합니다. 그래서 DRAM 컨트롤러는 64ms 안에 모든 행을 한 번씩 읽고 다시 써주는 작업을 반복합니다. 이것이 **리프레시(refresh)**입니다.

### 4-2. 리프레시의 대가

- **전력 소모**: 아무 일도 하지 않는 대기 상태에서도 리프레시 때문에 전력이 계속 소모됩니다. 서버·모바일에서는 이 대기 전력이 매우 중요합니다
- **성능 손실**: 리프레시 중인 행은 접근할 수 없습니다. 용량이 커질수록 리프레시할 행이 많아져 손실이 커집니다
- **불량 셀**: 수십억 개 셀 중 유난히 빨리 새는 셀이 존재합니다. 이런 셀 하나 때문에 칩 전체의 리프레시 주기를 짧게 잡아야 하므로, **최악의 셀이 전체 성능을 결정**합니다

> 따라서 **"누설을 줄여 리텐션을 늘린다"는 것은 곧 "리프레시 주기를 늘려 전력과 성능을 개선한다"**는 뜻입니다. 우리 프로젝트의 궁극적 목표가 바로 이것입니다.

## 5장. 누설전류 3형제와 GIDL

전하가 새는 경로는 여러 가지입니다. 주요한 세 가지를 봅시다.

### 5-1. 서브스레숄드 누설 (Subthreshold Leakage)

트랜지스터를 껐다고 해서 전류가 완전히 0이 되지는 않습니다. Vth 아래에서도 아주 작은 전류가 흐르는데, 이를 서브스레숄드 누설이라고 합니다. 채널이 짧아질수록 심해집니다.

### 5-2. 접합 누설 (Junction Leakage)

역방향으로 바이어스된 pn 접합에서도 미세한 전류가 흐릅니다. 결함(defect)이나 트랩(trap)이 있으면 더 커집니다.

### 5-3. GIDL — 우리 프로젝트의 주인공

> **GIDL(Gate-Induced Drain Leakage) = 게이트가 유발한 드레인 누설.** 게이트에 음의 전압이 걸리고 드레인에 양의 전압이 걸린 상태(즉 "확실히 꺼져 있어야 할" 상태)에서 오히려 드레인 쪽으로 흐르는 누설전류.

#### 왜 생기는가 — 단계별로

1. 트랜지스터를 끄기 위해 게이트에 낮은(또는 음의) 전압을 건다
2. 그런데 드레인에는 여전히 높은 전압이 걸려 있다. 게이트와 드레인이 겹치는(overlap) 영역에서 이 전압 차이가 매우 커진다
3. 얇은 게이트 산화막을 사이에 두고 큰 전압 차이가 걸리므로, 드레인 표면 부근에 **매우 강한 전기장**이 형성된다
4. 전기장이 너무 강하면 반도체의 에너지 밴드가 급격히 휘어진다 (**band bending**)
5. 밴드가 충분히 휘면, 원래는 전자가 있을 수 없는 위치에서 가전자대(valence band)의 전자가 전도대(conduction band)로 터널링해 넘어간다. 이를 **밴드간 터널링(Band-to-Band Tunneling, BTBT)**이라 한다
6. 넘어간 전자는 드레인 쪽으로 빠져나가 누설전류가 되고, 남겨진 정공(hole)은 반대 방향으로 흘러간다

> **GIDL의 결정적 특징**: 이것은 표면 현상이며, **게이트-산화막-드레인이 겹치는 영역에 극도로 국소화되어** 발생합니다. 즉 소자 전체가 아니라 아주 좁은 한 지점에서 일어납니다.

> 💡 **왜 이게 우리에게 중요한가**: GIDL이 이 겹침부에 집중된다면, **그 겹침 자체를 줄이는 것(DBCAT — 질화막을 두껍게 쌓아 금속 게이트를 표면에서 더 멀리 묻는 것)**만으로도 GIDL을 줄일 수 있다는 뜻입니다. 그리고 GIDL이 전기장의 세기에 의해 결정된다면, **전기장의 원인인 접합 도핑을 낮추는 것**으로도 줄일 수 있습니다. 우리 프로젝트의 두 변수가 정확히 이 두 갈래입니다.

#### 전계 집중(Field Crowding)이란

뾰족한 곳에 전기장이 몰리는 현상을 전계 집중이라고 합니다. 피뢰침이 뾰족한 이유와 같은 원리입니다. 반대로 모서리를 둥글게 만들거나 겹치는 면적 자체를 줄이면 전기장이 분산·완화됩니다.

BCAT는 게이트를 리세스 안에 묻는 구조라, 리세스를 채운 금속 게이트가 표면 근처에서 드레인과 어느 정도 겹칠 수밖에 없습니다. 이 겹침 영역의 크기(깊이)를 결정하는 것이 **DBCAT(질화막 두께)**입니다.

- DBCAT이 얇으면 → 금속 게이트가 표면에 가까워짐 → 게이트-드레인 겹침이 커짐 → 그 부위 전계가 강해져 GIDL이 커짐
- DBCAT이 두꺼우면 → 금속 게이트가 표면에서 멀어짐(질화막으로 대체) → 겹침이 작아짐 → GIDL이 줄어듦 (다만 유효 게이트 길이가 짧아져 SS·DIBL·Ion/Ioff는 나빠질 수 있음)

> **개정 메모**: 이전 버전에서는 "새들핀의 각진 코너(채널 내부, 리세스 바닥 쪽)"가 GIDL의 원인이라고 설명했으나, 이는 부정확했습니다. 그 코너는 베이스라인 논문에서 "핀 필렛 반경(Rfillet)"이라는 별도 변수로, 소자 신뢰성(산화막 내구성)에는 영향을 주지만 GIDL과는 직접 연결되지 않는다고 밝혀졌습니다. GIDL과 논문이 명시적으로 연결한 구조 변수는 DBCAT(질화막 두께)이며, 이 문서는 이를 반영해 수정되었습니다.

## 6장. 셀 트랜지스터의 진화 — 평면에서 BCAT까지

DRAM은 집적도를 계속 높여왔고, 그 과정에서 셀 트랜지스터의 모양이 계속 바뀌었습니다. 왜 바뀌었는지를 이해하면 BCAT의 존재 이유가 보입니다.

### 6-1. 문제의 출발 — 단채널 효과 (Short Channel Effect, SCE)

집적도를 높이려면 셀 하나가 차지하는 면적을 줄여야 하고, 그러면 트랜지스터의 채널 길이도 짧아져야 합니다. 그런데 채널이 너무 짧아지면 문제가 생깁니다.

- 게이트가 채널을 제대로 통제하지 못한다. 드레인 전압이 채널에 직접 영향을 미치기 시작한다
- Vth가 채널 길이에 따라 흔들리고, 꺼도 잘 안 꺼진다(누설 증가)
- 이 현상들을 통틀어 **단채널 효과**라고 한다

### 6-2. 해결의 아이디어 — 채널을 접어 넣자

> 평면 위에서 차지하는 면적은 그대로 두면서 채널 길이는 길게 확보하려면? → **채널을 기판 아래로 파고들어가게 만들면 된다.** (전개도를 접으면 면적은 줄고 길이는 유지되는 것과 같은 발상)

### 6-3. 구조 진화의 계보

| 세대 | 구조 | 핵심 아이디어 |
|---|---|---|
| 평면형 (Planar) | 일반 MOSFET | 채널이 표면에 평평하게 있음. 미세화하면 단채널 효과에 그대로 노출 |
| **RCAT** | Recess Channel Array Transistor | 게이트 아래를 U자로 파서(recess) 채널이 그 곡면을 따라 흐르게 함. 평면 면적은 그대로인데 채널 길이가 늘어남 |
| **S-RCAT** | Sphere-shaped RCAT | 파낸 바닥을 구(sphere) 형태로 넓혀 채널 길이를 더 확보 |
| **BCAT (새들핀)** | Buried Channel Array Transistor | 리세스 구조에 핀(fin) 형태를 결합. 게이트가 채널을 여러 면에서 감싸 통제력이 크게 향상됨. **우리가 다룰 구조** |
| 버라이드 워드라인 | Buried Word Line | 워드라인(게이트 배선)을 아예 기판 속에 묻어버림. 비트라인과의 기생 커패시턴스가 줄고 집적도가 올라감. 현재 양산 구조 |

### 6-4. 새들핀(Saddle-fin)이란

이름 그대로 말안장(saddle) 모양입니다. 실리콘 채널이 위로 솟은 핀(fin) 형태를 하고 있고, 게이트가 그 핀을 감싸 안는 구조입니다. FinFET과 비슷한 발상이지만, DRAM에서는 이것이 기판 아래로 파인 리세스 안에 들어가 있습니다.

우리 baseline 논문에서 이 구조를 이렇게 기술합니다: **새들핀 형태의 실리콘 채널이 질화막(Si₃N₄) 절연층 아래에 매립되어 있고, 텅스텐 게이트와 실리콘 산화막으로 덮여 있다.**

### 6-5. 얻은 것과 잃은 것

| 얻은 것 | 잃은 것 |
|---|---|
| 채널 길이 확보 → 단채널 효과 억제 | 구조가 3차원으로 복잡해짐 → 공정 난이도 상승 |
| 게이트 통제력 향상 → SS·DIBL 개선 | 게이트를 리세스에 묻어도 표면 근처에 게이트-드레인 겹침이 남음 → 그 부위에 전계가 집중 |
| 누설 감소 → 리텐션 개선 | 그 겹침 정도(DBCAT)를 잘 조절하지 않으면 오히려 GIDL이 커져 리텐션이 나빠질 수 있음 |

> 이 표의 **오른쪽 아래 칸**이 우리 프로젝트가 공략하는 지점입니다. BCAT는 좋은 구조지만, 게이트를 묻는 구조 자체가 만들어낸 겹침이 새로운 문제(GIDL)를 낳았습니다.

## 7장. Row Hammer — 겹침부 전계의 또 다른 얼굴

### 7-1. 무엇인가

Row Hammer는 특정 행(row)의 워드라인을 아주 빠르게 반복적으로 켰다 껐다 하면, **그 옆 행의 셀 데이터가 저절로 뒤집히는** 현상입니다. 2014년경 학계에 보고된 이후 실제 보안 취약점으로 다뤄지고 있습니다. 공격자가 이를 이용해 접근 권한이 없는 메모리 영역의 값을 바꿀 수 있기 때문입니다.

### 7-2. 왜 생기는가

1. 공격 대상 행(aggressor row)의 워드라인을 반복 활성화한다
2. 워드라인이 켜질 때마다 기판(p-well) 안에 순간적으로 강한 전기장이 생긴다
3. 이 전기장이 소량의 전자를 기판 영역으로 밀어넣는다(주입)
4. 주입된 전자들은 옆으로, 아래로 확산되어 퍼진다
5. 일부가 인접한 피해 셀(victim cell)의 스토리지 노드에 도달해, 저장된 전하를 상쇄시킨다
6. 반복될수록 전하가 깎여나가 결국 값이 뒤집힌다

### 7-3. 우리 프로젝트와의 연결

> **Row Hammer의 전자 주입은 게이트-드레인 겹침부 근처의 강한 전기장에서 시작됩니다. 이는 GIDL이 발생하는 바로 그 지점, 그 조건과 같습니다.** 따라서 그 겹침부 전계를 완화하는 설계는 GIDL 감소뿐 아니라 Row Hammer 내성 개선으로도 이어질 개연성이 있습니다.

⚠️ **주의**: 우리 프로젝트에서 Row Hammer를 **직접 시뮬레이션하지는 않습니다** (어레이 레벨의 반복 동작 시뮬레이션은 규모가 다릅니다). 우리는 "겹침부 전계 완화"라는 우리 결과가 Row Hammer 문헌에서 지목하는 메커니즘과 어떻게 연결되는지를 **서술적으로 확장**할 뿐입니다. 발표에서 이 선을 넘어 과장하지 않도록 주의하세요.

## 8장. 우리가 볼 숫자들 — 소자 특성 지표

시뮬레이션 결과는 결국 몇 개의 숫자로 요약됩니다. 각 숫자가 무엇을 뜻하는지 알아야 결과를 해석할 수 있습니다.

### 8-1. Id-Vg 곡선 읽는 법

가장 기본이 되는 그래프입니다. 가로축은 게이트 전압(Vg), 세로축은 드레인 전류(Id)이며, 세로축은 보통 로그 스케일로 그립니다.

- **오른쪽(Vg가 높은 쪽)**: 트랜지스터가 켜진 영역. 여기서의 전류가 **Ion**(온 전류)
- **가운데 급격히 올라가는 구간**: 문턱 근방. 이 기울기가 **SS**
- **왼쪽 평평한 바닥**: 꺼진 영역. 여기서의 전류가 **Ioff**(오프 전류)
- **왼쪽 끝에서 다시 살짝 올라가는 부분**: 이것이 **GIDL**. Vg를 더 낮췄는데 오히려 전류가 늘어나는 특징적인 "하키스틱" 모양이 나타납니다

> 💡 우리 프로젝트에서 가장 중요하게 볼 부분은 바로 이 **"왼쪽 끝의 올라가는 부분"**입니다. 여기가 낮아질수록 GIDL이 줄었다는 뜻이고, 곧 리텐션이 좋아진다는 뜻입니다.

### 8-2. 지표 정리

| 지표 | 정의 | 좋은 방향 | 우리 프로젝트에서의 의미 |
|---|---|---|---|
| **Vth** | 트랜지스터가 켜지는 문턱 게이트 전압 | 설계 목표값에 맞을 것 | DBCAT이 커질수록(질화막이 두꺼울수록) 유효 게이트 길이가 짧아져 Vth가 낮아지는 경향이 baseline에서 확인됨 |
| **SS** (Subthreshold Swing) | 전류를 10배 바꾸는 데 필요한 게이트 전압 (mV/dec) | 작을수록 좋음 | 게이트가 채널을 얼마나 잘 통제하는지의 척도. 60mV/dec가 상온 이론 한계 |
| **DIBL** | 드레인 전압이 Vth를 얼마나 끌어내리는지 (mV/V) | 작을수록 좋음 | 단채널 효과의 척도. DBCAT이 커질수록 악화되는 경향 |
| **Ion** | 켜진 상태의 전류 | 클수록 좋음 | 속도. 누설을 줄이려다 Ion이 너무 깎이면 손해 |
| **Ioff** | 꺼진 상태의 전류 | 작을수록 좋음 | 누설. 리텐션과 직결 |
| **GIDL 전류** | 음의 Vg 영역에서 흐르는 누설 | 작을수록 좋음 | **우리 프로젝트의 핵심 지표** |
| **리텐션 타임** | 데이터가 유지되는 시간 | 길수록 좋음 | 최종 목표. 누설이 줄면 늘어남 |

### 8-3. 트레이드오프 감각 익히기

소자 설계에서는 하나를 좋게 하면 다른 하나가 나빠지는 경우가 대부분입니다. 우리 프로젝트에서 예상되는 트레이드오프는 이렇습니다.

- 접합 도핑을 낮추면 → GIDL은 줄지만 → 저항이 커져 **Ion이 떨어질 수 있음**
- DBCAT을 너무 늘리면 → GIDL은 줄지만 → 유효 게이트 길이가 짧아져 **SS·DIBL이 나빠지고 Ion/Ioff비가 떨어질 수 있음**

> 그래서 우리의 진짜 질문은 **"GIDL을 얼마나 줄였나"가 아니라 "Ion(과 SS·DIBL)을 얼마나 지키면서 GIDL을 얼마나 줄였나"**입니다. 결과를 볼 때 항상 숫자를 짝으로 보세요.

## 9장. 우리 프로젝트로 돌아오기

이제 처음에 제시한 문장을 다시 읽어봅시다.

> **"BCAT는 게이트를 리세스 안에 묻으면서 표면 근처에 게이트-드레인 겹침이 남고, 그 겹침부에 전계가 집중돼 GIDL이 생겨 DRAM 리텐션을 떨어뜨린다. 우리는 그 겹침을 질화막으로 줄이는 것(DBCAT)과 접합 도핑을 낮추는 것, 이 두 방법이 서로 어떻게 상호작용하는지를 본다."**

### 9-1. 각 단어가 이제 무슨 뜻인지

| 단어 | 지금은 이렇게 이해할 수 있다 |
|---|---|
| **BCAT** | DRAM 셀의 접근 트랜지스터. 단채널 효과를 피하려고 채널을 기판 아래로 파고 핀 형태를 결합한 구조 (6장) |
| **게이트-드레인 겹침** | 게이트를 리세스에 묻어도 표면 근처에 남는 겹침 영역. 여기에 전기장이 몰림 (5-3, 6-5) |
| **GIDL** | 겹침부의 강한 전계 때문에 밴드가 휘어 전자가 터널링해 생기는 누설전류 (5-3) |
| **리텐션** | 셀이 데이터를 유지하는 시간. 누설이 크면 짧아지고, 짧아지면 리프레시를 자주 해야 해서 전력을 더 씀 (4장) |
| **DBCAT** | 질화막 두께. 이 값을 조절해 게이트-드레인 겹침을 줄이는 구조적 접근 (**우리 첫 번째 변수**, 5-3) |
| **접합 도핑 저감** | 접합부 도핑 농도를 낮춰 전계 자체를 약화시키는 도핑적 접근 (**우리 두 번째 변수**, 2-3) |
| **상호작용** | 두 방법이 독립적인지, 아니면 한쪽이 다른 쪽의 최적점을 바꾸는지 — **아무도 검증하지 않은 지점** |

### 9-2. 왜 "상호작용"이 핵심인가

두 방법 각각의 효과는 이미 논문에 있습니다. 우리가 그걸 다시 확인하는 것만으로는 새로운 기여가 되지 않습니다. 하지만 이런 질문은 아직 답이 없습니다.

- DBCAT을 늘리면 유효 게이트 길이가 짧아지는데, 그러면 최적의 접합 도핑도 달라지지 않을까?
- 한쪽만으로는 한계에 부딪히는 지점에서, 다른 쪽이 그 한계를 보완해주지 않을까?
- 반대로 둘을 같이 하면 서로 상쇄되어 오히려 손해가 되는 조합은 없을까?

이 질문들에 답하려면 두 변수를 각각 따로 스윕해서는 안 되고, 격자 형태로 함께 바꿔가며 봐야 합니다. 그래서 **우리 결과물은 두 개의 선 그래프가 아니라 하나의 2차원 등고선**입니다. (등고선을 구체적으로 어떻게 만들고 읽는지는 [프로젝트 통합 기획서 4-4절](project-plan.md) 참고.)

| DIBL | Drain-Induced Barrier Lowering. 드레인 전압이 Vth를 끌어내리는 정도 |
| Destructive Read | 읽으면 원래 데이터가 망가지는 성질. DRAM 고유의 특징 |
| Elevated S/D | 소스/드레인을 기판 위로 올린 구조. 접합 저도핑으로 전계·누설을 낮춤 |
| Field Crowding | 전계 집중. 뾰족한 곳이나 겹침이 큰 곳에 전기장이 몰리는 현상 |
| GIDL | Gate-Induced Drain Leakage. 게이트가 유발한 드레인 누설 |
| GIJL | Gate-Induced Junction Leakage. 게이트 유발 접합 누설 |
| Ion / Ioff | 켜진 상태 전류 / 꺼진 상태 전류 |
| Junction | 접합. 서로 다른 극성으로 도핑된 영역의 경계 |
| Precharge | 읽기 전에 비트라인을 중간 전압으로 충전해두는 동작 |
| Recess | 리세스. 기판을 파낸 홈 |
| Refresh | 데이터가 사라지기 전에 다시 써넣는 주기적 동작 |
| Restore / Write-back | 파괴적 읽기 후 원래 값을 다시 써넣는 동작 |
| Retention Time | 데이터가 유지되는 시간 |
| Row Hammer | 특정 행을 반복 활성화해 인접 행의 데이터를 뒤집는 현상/공격 |
| Saddle-fin | 말안장 모양의 핀 구조 채널 |
| SCE | Short Channel Effect. 채널이 짧아질 때 생기는 여러 열화 현상 |
| Sense Amplifier | 센스앰프. 비트라인의 미세한 전압 차이를 증폭해 0/1을 판별하는 회로 |
| SS | Subthreshold Swing. 전류를 10배 바꾸는 데 필요한 게이트 전압(mV/dec) |
| Storage Node | 전하가 실제로 저장되는 지점 |
| Vth | Threshold Voltage. 문턱전압 |
| Word Line (WL) | 행을 선택하는 가로 배선. 셀 트랜지스터의 게이트에 연결 |
