# Devlog 작성 템플릿

새 로그를 추가할 때 아래 블록을 통째로 복사해서 `devlog.md` 맨 위(최신 항목 바로 아래)에 붙여넣고 채운다. 항목이 없으면 해당 줄은 지운다.

```markdown
## YYYY-MM-DD — 한 줄 제목

### 한 일
-

### 결정 사항
-

### 막힌 점 / 리스크
-

### 다음 할 일
- [ ]

### 참고
-
```

## 작성 팁

- "한 일"은 결과가 아니라 시도한 것까지 포함해서 적는다 (실패한 시도도 나중에 흐름을 보여주는 데 중요함).
- 회의 직후 5분 안에 초안만 채우고, 커밋은 그날 안에 한다 — 나중으로 미루면 디테일이 사라진다.
- 커밋 메시지는 devlog 제목과 맞춘다. 예: `git commit -m "devlog: Nonlocal Mesh 캘리브레이션 1차 시도"`
- 코드나 결과 그래프를 같이 올릴 땐, "참고" 항목에 저장소 내 상대경로를 링크로 남긴다 (예: `tcad/results/2026-08-05_idvg.png`).
