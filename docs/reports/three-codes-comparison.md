# 3개 구조 코드 비교 분석

NSFET 3-stack · Nanowire(SBTE) · Nanowire(NEGF) SProcess 코드 해설과 차이

> 세 파일 모두 학교 Sentaurus 라이선스(AdvancedTransportPackage) 안의 GAA 소자 구조 생성 스크립트입니다. 이 문서는 원본 코드를 그대로 인용하지 않고, 각 코드가 하는 일과 서로의 차이를 말로 풀어 설명한 분석 노트입니다. 편의상 아래처럼 부릅니다.
>
> - 코드 A = NSFET_SdeviceSBTE_3nm (3층 나노시트)
> - 코드 B = Nanowire_Si_QTX_SBTE_5nm (단일 나노와이어, KMC 옵션 포함)
> - 코드 C = Nanowire_Si_QTX_NEGF_5nm (단일 나노와이어, 단순 버전)

## 1. 세 줄 요약

- A는 시트를 3층 쌓는 유일한 코드 — 팀의 핵심 주장("스택이 늘수록 Ion 증가")을 보여줄 수 있는 것은 A뿐.
- B와 C는 사실상 형제 코드 — 둘 다 단일 나노와이어(원형/사다리꼴)를 만들고 구조 로직이 거의 같음. 차이는 B가 KMC 이산도핑·명시적 전극 등 기능이 더 많고, C는 그걸 덜어낸 더 단순한 버전이라는 것.
- 입문은 C(가장 단순) → 검증은 B → 본론은 A 순서가 가장 안전.

## 2. 코드 C 상세

### 2-1. 재료·매크로 정의

Silicon을 베이스로 하는 소스/드레인 태그 재료(SiSD), Oxide를 베이스로 한 Low-k 스페이서 재료(LowK)를 등록합니다. 코드 B가 `set`(변수)로 쓰던 것을 C는 `#define`(매크로)으로 씁니다 — 기능은 동일: 채널=Silicon, 소스/드레인=SiSD 태그, 도핑값은 Workbench 파라미터. 참고로 B에 있던 KMC용 재료 옵션과 좌표계 설정이 C에는 없습니다(KMC를 안 쓰기 때문).

### 2-2. 구조 생성 — 원형/사다리꼴

Workbench 파라미터로 단면 형태(원형/사다리꼴)를 선택합니다. 원형을 선택하면 원통(Cylinder) 도형으로 바깥부터 게이트 산화막 → 채널 실리콘 → 소스/드레인 → 스페이서 순으로 겹겹이 생성합니다. 사다리꼴을 선택하면 6면체(HexaHedron) 도형으로 같은 순서를 만듭니다.

- 코드 B와 똑같이 원통 또는 6면체로 GAA 나노와이어를 만듭니다.
- 좌표계 주의: C는 원통 축이 z(채널 길이=z축), B는 축이 x(채널 길이=x축)입니다. 두 코드의 좌표 규약이 반대라 섞어 쓸 때 혼동 주의.
- 게이트 금속(Tungsten) 생성 코드는 비활성화 상태로 남아있음 — 즉 지금은 금속을 안 만들고, SDevice에서 산화막 표면에 직접 게이트 전극을 잡는 방식(양자수송 이상화 구조).

### 2-3. 도핑·열처리·마무리

도핑 방식(pMOS/nMOS에 따라 채널·소스/드레인 도펀트 종류 결정, 소스와 드레인에 동일 도펀트 적용)과 800도·1100도 2단계 레이저 스파이크 어닐은 코드 B와 동일합니다. 다만 C에는 B에 있던 KMC 이산도펀트 분기와 명시적 전극(contact) 정의 블록이 없습니다 — 그만큼 단순합니다.

## 3. 코드 B vs 코드 C — 형제 코드의 차이

| 항목 | 코드 B (SBTE) | 코드 C (NEGF·단순) |
|---|---|---|
| 변수 선언 | set 사용, 좌표계 명시 설정 있음 | #define 사용, 없음 |
| KMC 이산도핑 | 스위치로 지원 | 없음 (연속 도핑만) |
| 좌표 규약 | 채널 길이 = x축 | 채널 길이 = z축 |
| 원통 축 | X축 | Z축 |
| 게이트 금속 | 없음(표면 전극) | 비활성화(표면 전극) |
| 전극 정의 | box/sidewall 명시 블록 있음 | 이 파일엔 없음(별도 처리 추정) |
| 디버그 저장 함수 | 없음 | 있음(단계별 구조 저장) |
| 복잡도 | 높음(기능 많음) | 낮음(입문용으로 적합) |

> B와 C는 만들어내는 소자(GAA 나노와이어)가 사실상 같습니다. 학부 프로젝트라면 KMC 같은 고급 기능이 없는 C가 이해·수정이 쉬워 시작점으로 더 낫습니다.

## 4. 세 코드 종합 비교

| 항목 | A: NSFET 3-stack | B: NW SBTE | C: NW NEGF |
|---|---|---|---|
| 채널 구조 | 나노시트 3층 스택 | 단일 나노와이어 | 단일 나노와이어 |
| 단면 형태 | 사각+둥근끝(스타디움) | 원형/사다리꼴 선택 | 원형/사다리꼴 선택 |
| 스택 스윕 | 가능(nStack) | 불가(1개) | 불가(1개) |
| High-k 층 | Oxide+HfO2 명시 | 단일 산화막(EOT) | 단일 산화막(EOT) |
| 게이트 금속 | Tungsten 실제 생성 | 없음 | 비활성화 |
| 이산도핑(KMC) | 없음 | 있음 | 없음 |
| 열처리 | 500도 저열예산 | 레이저 800/1100 | 레이저 800/1100 |
| 난이도 | 높음 | 중간 | 낮음 |
| 팀 활용 | 본론(핵심주장) | 검증·심화 | 입문·최초확인 |

## 5. 팀 전략 제안

- **1단계(입문)** — 코드 C(원형)로 GAA-TFET 하나가 실제로 켜지는지, BTBT로 SS < 60 mV/dec가 나오는지 최단 경로로 확인. 구조가 가장 단순해 오류를 잡기 쉬움.
- **2단계(검증)** — 코드 B로 옮겨 같은 나노와이어를 조금 더 정교하게(필요시 사다리꼴 단면 등) 확인. KMC는 끄고 진행.
- **3단계(본론)** — 코드 A로 이동해 nStack=2/3/4 스윕으로 "시트를 쌓을수록 Ion이 비례해 증가하고 SS는 유지된다"는 핵심 주장을 정량 입증. 이게 발표의 하이라이트.
- **공통 필수 수정** — ① 소스/드레인을 반대 도펀트로 분리해 p-i-n(TFET) 만들기, ② SDevice 물리모델을 SBTE/NEGF → classical Band2Band(NonlocalPath)로 교체, ③ Ambipolar 억제용 소스/드레인 비대칭 적용.

> 세 코드 모두 지금은 표준 MOSFET(소스·드레인 동일 도펀트) 도핑입니다. TFET으로 바꾸는 핵심 수정(소스 p+ / 드레인 n+ 분리)은 세 코드 모두 도핑 지정 블록에서 똑같이 해줘야 합니다.
