# FinFET + Embedded SiGe Source/Drain 응력공학

차세대반도체 경진대회(POLARIS SIF) 소자/공정 부문 출품 프로젝트.

기존 **FinFET** 구조의 Source/Drain을 선택적 에피택시(SEG)로 **SiGe**로 대체(in-situ 도핑)해 PMOS 채널에 압축 응력을 유도한다. 스윕 축은 **Ge 조성(%) × 리세스 깊이(nm)**. Sentaurus로 이 2차원 전 구간의 응력·이동도를 계산하고, 그 위에 문헌 기반 임계두께 경계선(People-Bean/Luryi-Suhir)을 겹쳐 "어느 조합부터 전위결함으로 응력 이득이 무효화되는지" 결함 발생 경계(trade-off boundary) 지도를 그린다.

## 핵심 질문

> Ge 조성(%)과 리세스 깊이(nm)를 얼마나 밀어붙여야 응력/이동도 이득이 전위결함(소성 완화)으로 무효화되기 시작하는가?

"~ 최적화"가 아니라 **"기존 FinFET 구조 + 새 공정(SiGe eS/D) → 개선"** 흐름을 따른다. 결과물은 응력 최댓값을 찾는 것이 아니라, **결함 발생 경계 지도**다 — 두 개의 1차원 최적값이 아니라, 두 변수를 격자로 함께 스윕한 2차원 등고선 위에 문헌 기반 경계선을 오버레이한 것이다.

## 왜 이 주제인가

| 기준 | 근거 |
|---|---|
| **양산성** | FinFET은 2026년 8월 현재도 GAA와 병행 생산 중이며 물량 기준 최대 노드(TSMC N3)다. Apple M4, AMD MI350 등 최신 제품이 여전히 FinFET 기반 |
| **완주 가능성** | Synopsys Sentaurus Applications Library의 `FinFET_14nm`/`FinFET_22nm` 예제를 구조 출발점으로 쓸 수 있음 (단, 이 예제가 Intel 22nm Tri-Gate/PTM 14nm에 실제로 대응하는지는 파일명 기반 추측일 뿐 미검증 — 최우선 확인 과제) |
| **독창성** | 가장 근접한 선행연구(Gendron-Hansen et al., SISPAD 2015)는 축(기술노드 세대)과 목표(응력 최대화)가 우리와 다름 — 우리 축은 Ge%×리세스 깊이, 목표는 결함 경계 매핑 |
| **전환 사유(4단계)** | 직전 주제(DBCAT×접합도핑)는 2026 POLARIS SIF 실제 수상작과 조합이 겹쳐 독창성이 약해졌다는 것이 이번 전환의 직접 계기 |

> **정직한 겹침 인정**: "TCAD+FinFET+eSiGe" 조합 자체는 2012년(Choi et al., Synopsys)부터 다뤄진 성숙한 방법론이다. 우리 기여는 새 방법론의 발명이 아니라 **Ge%×리세스 깊이라는 특정 2차원 축에서 결함 경계를 정량적으로 매핑**한 것이다.

## 문제 배경 (요약)

- **Ge 조성**: Vegard's law에 따라 Ge%가 높을수록 SiGe의 자연 격자 상수가 커진다. Si 기판 위에 정합 성장하면서 억지로 눌린 압축 변형이 되고, 이 변형이 채널 실리콘까지 전달돼 정공 이동도를 높인다. 다만 Ge%가 높을수록 버틸 수 있는 두께(임계두께)는 줄어든다.
- **리세스 깊이**: 격자 차이와 무관한 순수 기하학적 변수. 깊을수록 SiGe 부피·채널 근접성이 늘어 응력 전달이 세지지만, 무한정 좋아지진 않는다 — 적당한 오버필에서 최대가 되는 비단조적 거동이 문헌으로 확인됨.
- **임계두께를 넘으면**: 전위결함(소성 완화)이 생겨 응력 이득이 무효화된다. Sentaurus의 응력 계산은 완전정합(pseudomorphic) 가정의 선형탄성 기반이라 이 결함 발생 자체를 자동으로 반영하지 않는다 — 그래서 문헌 기반 경계선(People-Bean/Luryi-Suhir)을 등고선 위에 별도로 오버레이하는 하이브리드 방법론을 쓴다.

## 베이스라인

**Synopsys Sentaurus Applications Library — `FinFET_14nm` / `FinFET_22nm` 예제.**

> 논문 재현이 아니라 툴 제공 예제 구조를 출발점으로 쓴다. 이 예제가 Intel 22nm Tri-Gate / PTM 14nm에 대응한다는 것은 **파일명 기반 추측이며 미검증**이다 — 학교 라이선스로 예제를 직접 열어 치수 스펙을 대조하는 것이 최우선 과제.

## 사용할 공식 (등고선에 경계선 그릴 때 둘 다 적용)

- **People-Bean (1985)**: 평면(blanket) 기준 임계두께 근사식 Tc≈1.23×x⁻³·⁰⁸ (nm). 단, Hartmann et al., *J. Appl. Phys.* 110, 083529 (2011)의 실측(XRD) 결과 Ge 22% 이상에서 이 근사식이 실제보다 최대 ~2배 더 보수적(과소평가)이라는 것이 확인됨 — 「보수적 하한」으로만 쓴다.
- **Luryi-Suhir (1986)**: fin처럼 좁은 메사 구조는 옆면(자유 표면)을 통한 탄성 완화로 임계두께가 평면 기준보다 늘어난다. 경험식: fin 폭 W < 15×Tc(People-Bean 평면값)이면 결함 없이 버틸 수 있음.

두 선 사이는 "평면 기준으론 위험해 보이지만 실제 fin 구조에서는 안전한 영역"이고, Hartmann(2011) 결과를 더하면 "이중으로 보수적으로 잡아도 안전한 영역"이라는 더 강한 주장이 된다. 상세 근거·출처는 [references.md](docs/references.md) 참고.

## 팀 역할 분담

작업 종류(구조/물리/분석)가 아니라 **격자 좌표(Ge% 열) 기준**으로 나눈다 — 한 사람이 막혀도 나머지가 대기하지 않고, 전원이 TCAD 실행부터 결과 해석까지 전체 사이클을 경험하게 하기 위함 (2026-08-03 devlog 항목 "역할 분담을 작업 종류에서 격자 좌표로 변경" 참고).

- 2차원 격자를 **Ge% 기준 세로 3등분**해서 낮은/중간/높은 열을 각 1인이 담당
- 중간 열 담당자는 공칭(baseline) 조건을 포함하므로, 인접한 양쪽 열과 모두 교차검증
- 이와 별개로 각자 개별 추가 조사 과제(모델 검증·메쉬 수렴성·라이선스 확인 등)를 1개씩 맡는다
